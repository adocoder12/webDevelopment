# Go Web Development Learning

A dedicated repository documenting my journey and progress in learning the Go (Golang) programming language, with a focus on core web development principles.

## 🎯 Learning Objectives
This project tracks my hands-on experience with the Go standard library and common web patterns:
* **HTTP Foundations:** Utilizing the `net/http` package to build robust servers.
* **Request Handling:** Implementing handlers, muxers, and processing URL parameters.
* **Data Structures:** Applying Go structs and types to manage application state.
* **Web Mechanics:** Understanding the lifecycle of an HTTP request within a Go application.

## 📁 Project Overview
The repository is structured to showcase clean, idiomatic Go code as I progress through different modules:

* **Server Implementation:** Building and configuring the base web server.
* **Routing Logic:** Mapping endpoints to logic using standard library methods.
* **Dependency Management:** Utilizing `go.mod` for modern Go versioning and module control.

## 🛠 Setup and Usage

### Prerequisites
* **Go** (Latest stable version recommended)

### Installation & Execution
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/adocoder12/webDevelopment.git
    ```
2.  **Navigate to the folder:**
    ```bash
    cd webDevelopment
    ```
3.  **Run the application:**
    ```bash
    go run .
    ```
